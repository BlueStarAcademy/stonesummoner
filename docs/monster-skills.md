# 소환수 역할·스킬 설계

## 역할 5종

| 역할 | 주 스탯·피해 기준 | 전투 기여 |
|---|---|---|
| 공격형 | ATK | 단일/광역 피해, 치명, 처형 |
| 체력형 | 최대 HP | 자가회복, 지속회복, 피해분담 |
| 방어형 | DEF | 도발, 실드, 반사, 방어 강화 |
| 속도형 | SPD | ATB 조작, 속도 강화·약화, 쿨타임 조작 |
| 지원형 | 효과 적중·회복 | 회복, 정화, 해제, 면역, 부활, 침묵 |

태생 성급은 기본 스탯과 피해 예산을 결정한다. 역할과 패밀리 정체성은
효과·대상·확률·지속 턴·쿨타임을 결정하며, 별도 피해 배율을 중복 적용하지 않는다.

## 스킬 슬롯

- S1: 기본 공격 + 낮은 확률 또는 낮은 강도의 역할 부가효과
- S2: 패밀리 전술을 드러내는 2–4턴 기술
- S3: 패밀리 대표 효과를 가진 3–6턴 기술
- ★4–5 차별화는 피해 계수보다 효과 범위·상태 수·정화/해제 수로 제공

## 패밀리 정체성

50개 패밀리는 `familyIdentity`와 `combatTags`를 갖는다. 같은 역할·속성이라도
S2/S3 효과 조합이 같지 않아야 한다. 독·저주·치유·수호·암살·진문·포획 등
기존 이름의 의미가 실제 효과와 일치해야 한다.

## 상태 규칙

- 해로운 효과는 스킬 발동 확률 판정 후 ACC/RES 저항 판정을 거친다.
- 최종 저항 확률은 15–85% 범위다.
- 기절·빙결·수면·침묵은 서로 다른 상태다. 수면은 피해를 받으면 해제된다.
- `strip`과 `cleanse`는 지정 개수만 제거하며, 제거 우선순위가 결정적이어야 한다.
- 상징 패시브와 바둑 팀 버프는 스킬 상태 저장소와 분리한다.
- 부활은 전투 중 쓰러진 소환수만 대상으로 하며 소환사는 대상이 아니다.

## AUTO 원칙

AUTO는 피해량만 보지 않는다. 부활, 치명상 회복, 정화, 해제, 위험 적 제어,
ATB 조작, 지속피해 갱신 순으로 상황 가치를 평가하고 이미 활성화된 상태를
불필요하게 중복 사용하지 않는다.
