- **슬롯·강화·주/부옵션 수치표** = SW 룬 원천 이관

등급 매핑: 일반~신화 ≈ SW **1★~6★** (신화=6★)

## 4. 강화 규칙

- 강화 +0 ~ +15
- +3 / +6 / +9 / +12: 부옵션 개방 또는 강화
- 접두어(연마): 강화로 오르지 않음
- 각인(보석): 부옵션 재부여/상향

## 7. Phase 1

- 슬롯 1–6 + 강화 +15
- 세트 2~3종만 (예: 활로·용맹·행마) → Phase 2에서 8종으로 확장
- [x] 각인 스텁: 슬롯 4–6 주옵션 재부여 (크리스탈)
- [x] 연마 스텁: 접두어 부여/재부여 (마나, 강화로 오르지 않음)
- [x] 마법상점 스텁: 소환서 마나 구매
- [x] Phase 2 세트: 굳힘·무쌍·침투·보강·집중 (+심층 드롭)
