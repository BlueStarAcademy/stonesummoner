## 4. 강화 규칙

- 강화 +0 ~ +15
- +3 / +6 / +9 / +12: 부옵션 개방(최대 4) 또는 기존 부옵션 강화
- 접두어/부옵션 연마: 연마석 1 + 골드 — 부옵션이 있으면 부옵션 강화, 없으면 flat 접두어 부여/재부여 (강화로 오르지 않음)
- 각인 스텁: 슬롯 **2/4/6** 주옵션 재부여 (크리스탈). SW 보석(부옵션 재부여)은 후속
