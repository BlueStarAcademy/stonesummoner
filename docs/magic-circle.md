# 마법진 (Magic Circle) — 모듈 카탈로그

공유 바둑판. 기본: 착수 · 따냄 · 아이템.  
콘텐츠별로 모듈을 켜고 끈다. 농사는 최소화, 고난도에서 겹친다.

## 전투용 바둑 규칙 (축소)

- 활로 0 → 따냄 → 마나 가속 + Amplify
- 자살수 금지, 패(ko) 한 수 금지
- **집 계산 없음** — 승패는 유닛 HP
- 보드 크기: **5×5 → 7×7 → 9×9** 진행 (상세: [board-progression.md](board-progression.md))
- 장기전: **9×9에서 착수 50회** 후 보드 초기화 + **강화 진문**으로 재개

돌 ≠ 몬스터. 돌은 전장 자원.
