# 마법진 보드 크기 · 페이즈 진행

## 1. 크기 진행 (학습 → 정규)

전투·콘텐츠 해금에 따라 보드가 **조금씩 커진다.**

| 단계 | 크기 | 교차점 | 용도 |
|------|------|--------|------|
| 입문 | **5×5** | 25 | 튜토리얼·초반 시나리오 |
| 성장 | **7×7** | 49 | 중반 시나리오·초급 심층 |
| 정규 | **9×9** | 81 | 후반·심층·아레나·레이드 기본 |

보스 초대형(13×13)은 Phase 2+ 옵션으로 유지하되, **주력 장판은 9×9**다.

### 해금 가이드 (초안)

| 조건 | 보드 |
|------|------|
| 서머너 Lv1~ / 시나리오 맵1 초반 | 5×5 |
| 맵 중반 또는 Lv 구간 돌파 | 7×7 |
| 맵 후반·심층·PvP | 9×9 |

Phase 1: 시나리오 1챕터는 **5×5로 시작**, 챕터 후반 스테이지에서 **7×7** 일부 배치. 9×9는 챕터 클리어 후 해금해도 됨.

## 2. 장기전 — 9×9 리셋 페이즈

전투가 길어지면 보드가 가득 차 국면이 정체된다.  
**9×9에서 착수(스톤소환) 50회**가 쌓이면:

1. 현재 9×9 보드의 돌·토큰·패 상태를 **초기화**(빈 판)
2. **더 강력한 9×9 진문**으로 교체되어 전투 계속
3. 유닛 HP·버프·마나·ATB는 **유지** (보드만 리셋)
4. `boardPhase` 카운터 +1

```text
stoneSummonCount += 1  // 양측 착수 합산 (또는 아군만 — 기본: 양측 합산)
if boardSize == 9 and stoneSummonCount >= 50:
  clearBoard()
  boardPhase += 1
  stoneSummonCount = 0
  applyEmpoweredCircle(boardPhase)
```

### 「더 강력한 9×9」 효과 (`boardPhase`별)

| Phase | 이름(가칭) | 효과 |
|-------|------------|------|
| 0 | 일반 진문 | Amplify 상한 1.25, 아이템 기본 |
| 1 | 강화 진문 I | Amplify 상한 **1.30**, 아이템 스폰 +20%, 따냄 마나 +10% |
| 2 | 강화 진문 II | Amplify 상한 **1.35**, 사석자석 가중↑, 형상/이벤트 모듈 개방 가능 |
| 3+ | 극진 | Amplify 상한 **1.40** (ΔPower 캡과 별도 클램프), 보스 모듈 일부 |

상한은 여전히 **상징 티어 ΔPower 캡**과 `min()` 한다 — 약한 덱이 장기전만으로 강적을 학살하지 못하게.

### 연출

- 50수 도달 시 마법진이 붕괴 → 재점화
- UI: `진문 재건 I` / `II` 표시
- 리셋 직후 1수는 「포석 보너스」(양측 중앙 근처 추천) 가능

### 카운트 정의

- **기본:** 양 진영 스톤소환(착수) 성공 횟수 합 = 50  
- 패스/스킬만 보드 미개입은 카운트하지 않음  
- 자동·수동 동일

## 3. 크기별 UX

| 크기 | 보드 화면 비율 | 비고 |
|------|----------------|------|
| 5×5 | ~18–22% | 돌 크게, 학습용 하이라이트 강조 |
| 7×7 | ~20–25% | |
| 9×9 | ~22–28% | 목업 기준 |
| 리셋 직후 | 동일 9×9 | 섬광 연출만 추가 |

## 4. 엔진 API (packages/board)

```ts
export const BOARD_SIZES = [5, 7, 9] as const;
export type CombatBoardSize = 5 | 7 | 9;

export interface CirclePhaseState {
  size: CombatBoardSize;
  stoneSummonCount: number;
  boardPhase: number; // 0 = 일반, 1+ = 강화 진문
  resetThreshold: number; // 9×9일 때 50
}
```

`shouldResetEmpoweredNine(state)` → true면 보드 clear + phase++.
