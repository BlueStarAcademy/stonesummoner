# 소환사 (Summoner)

SW에 없는 StoneSummoner 핵심 차별 요소.

> **Phase 2:** 속성별 **고유 리더스킬** + **마법 스킬트리**(기초 2 → +5 시 상위 2 → 전투 4스킬).  
> 상세 스펙: [summoner-phase2.md](summoner-phase2.md) · 데이터: `packages/data/src/summoners.ts`

## 0. SW와의 역할 분리

| 역할 | 서머너즈워 | StoneSummoner |
|------|-----------|---------------|
| 리더스킬 | 몬스터에 부착 | **소환사만** (고유 리더 + 각성·장비 가산) |
| 전투 고유기 | 몬스터 액티브 | 소환사 **마법 스킬(최대 4)** + 몬스터 S1~S3 |
| 성장 트리 | (해당 없음) | 소환사 **마법 강화 0~5** + (레거시 15노드 패시브 병행) |

소환수는 속성별 동일 이름·다른 스킬 키트만 담당하고, **리더스킬을 갖지 않는다**.

## 1. 역할

- 진영 **후열**에 배치 — **공격 대상이 아님** (무적 지휘관)
- ATB · 스톤소환(착수) · 스킬만 수행
- **마나** 조건 충족 시 소환사 전용 마법 스킬 (적 **소환수**에게만 피해)
- 승패: **적 소환수 전멸 = 승리** / **아군 소환수 전멸 = 패배**

파티: **소환사 1(후열) + 몬스터 4(전열)**

## 2. 성장

| 항목 | 내용 |
|------|------|
| 레벨 | 소환사 레벨 (건물 해금·기본 스탯) |
| 각성/초월 | 영구 마나·스킬·리더 보너스 (0~5) |
| 스킬 | **Phase 2 마법 트리** (기초 A/B + 분기 상위) · 레거시 15노드 패시브 |
| 장비 | 몬스터 상징과 **별개** |

### Phase 2 마법 스킬트리

1. 기초 A·B 시작부터 사용 가능
2. 각 스킬 강화 0~5 (`runEnhanceMagicSkill`)
3. **최초 +5** 달성 쪽의 상위 2스킬 해금
4. 전투 보유 = **4스킬**

### 소환사 스킬 트리 (Phase 1 레거시 · 얕은 스텁)

소환사 성장 UI에서 해금. 선행 노드 + 소환사 레벨 + 마나(/크리스탈). 마나 회로·국면 감응 패시브용으로 유지.

| 노드 | 효과 |
|------|------|
| 진액 회로 / 국면 눈 / 진문 핵 | 루트 3갈래 (regen·sense·스킬위력) |
| 심연 저장 / 선취 감응 / 개방 집중 | 각 갈래 2단 |
| 지휘 파동 | 리더 ATK · HP (마나+스킬 루트 필요) |
| 쌍착 숙련 / 청소 숙련 | 스킬 마나 할인 · 청소 Amp |
| 증폭 숙련 / 심연 우물 / 국면 조류 | Lv10 각 갈래 심화 |
| 쌍착 심화 / 청소 심화 | Lv10 숙련 심화 (마나 추가 할인) |
| 전장 합창 | Lv12 리더+스킬 (지휘+쌍착 필요) |

### 소환사 각성 (Phase 1 스텁)

강화진에서 수행. 단계마다 소환사 레벨 게이트 + 마나·크리스탈 소모.

| 단계 (현재→다음) | 최소 Lv | 마나 | 크리스탈 |
|------------------|---------|------|----------|
| 0→1 | 5 | 500 | 3 |
| 1→2 | 8 | 900 | 5 |
| 2→3 | 11 | 1300 | 7 |
| 3→4 | 14 | 1700 | 9 |
| 4→5 | 17 | 2100 | 11 |

단계당 전투 보너스 (누적):

- 마나 regen +0.06 / manaMax +8 / boardSense +0.015 / 시작 마나% +1% / skillPower +0.025
- 소환사 유닛 HP +30 · DEF +3
- 아군 몬스터 ATK +1.2%/단계 · HP +0.6%/단계 (리더형)

## 3. 소환사 장비

### 슬롯 (Phase 1 스텁: 6부위)

| 부위 | 주 효과 축 |
|------|------------|
| 무기 | 스킬 위력 (진문개방 계수) |
| 로브 | 생존 (HP/DEF) |
| 장신구 | 마나 회로 |
| 마법구 | 국면 감응 (보드→마나) |
| 망토 | 생존 + 리더형 ATK% |
| 반지 | 스킬 위력 + 리더형 ATK% |

스타터: **지휘 망토** (리더 +0.8%) · **결속 반지** (리더 +1.0%)  
강화 시 망토/반지 리더 %·생존/스킬이 소폭 상승. 각성 리더와 합산되어 아군 몬스터에 적용.

### 장비 세트 (얕은 5종 · 2/4/6)

| 세트 | 2세트 | 4세트 | 6세트 |
|------|-------|-------|-------|
| 진액 (mana) | regen·manaMax | 시작 마나%·manaMax | regen·manaMax |
| 돌격 (assault) | 스킬 위력·리더 ATK | 추가 스킬·리더 | 추가 스킬·리더 |
| 수호 (guardian) | 소환사 HP/DEF | 추가 HP/DEF | 추가 HP/DEF |
| 감응 (sense) | boardSense | sense·regen | sense·시작마나 |
| 진속 (tempo) | 시작마나·sense | 시작마나·스킬 | regen·리더 |

- 스타터: 무기+반지=돌격2 · 로브+망토=수호2 (즉시 활성)
- 세트 부여: 강화진/CLI `set-gear` · 마나 180 · 부위별 세트 교체
- 6세트: 동일 세트 6부위 장착 시 (풀 모노세트)

### 효과 축

| 축 | 설명 |
|----|------|
| 생존 | 소환사 HP·방어 |
| 마나 회로 | 기본 마나 충전 속도, 시작 마나 %, 상한 |
| 국면 감응 | 따냄·형상·아이템당 보너스 마나 |
| 스킬 위력 | 소환사기 계수·마나 소모 |
| 리더형 | 아군 전원 소폭 버프 |

- 강화: 상징보다 단순 (**+0~+15**) · +9 이후 마나 가속 · **+12 이후 크리스탈** (1/2/3)
- 세트: 마나특화 / 돌격 / 수호 / 국면감응 / 진속 — **얕게** (2/4/6세트, 상징과 규모 경쟁 금지) [x]

### 랜덤 롤 (`rollSeed`)

장비 1개는 **시드 1개**(`rollSeed`)만 저장하고, 아래 세 값을 시드에서 결정론적으로 파생한다. 시드가 없는 레거시 장비는 `id` 해시로 안정적인 시드를 얻는다.

| 값 | 규칙 |
|----|------|
| 주 스탯 편차 (`rollPct`) | ★1–2 0.90–1.10 · ★3 0.88–1.14 · ★4 0.86–1.18 · ★5 0.85–1.22 |
| 부옵션 (`subStats`) | ★1 0개 · ★2–3 1개 · ★4 2개 · ★5 2개(25% 확률 3개), 해당 부위의 주 스탯 축과 겹치지 않는 축에서만 |
| 특수 능력 (`affixes`) | ★3 이하 없음 · **★4 1개** · **★5 2개**(중복 id 없음) |

### 특수 능력 (`GEAR_AFFIXES`)

같은 특수 능력은 **로드아웃 전체에서 1개만 발동**하며 가장 높은 롤을 채택한다 (골드 2배 중첩 불가). 모든 전투에 적용.

| 경제형 | 효과 | 최소 ★ |
|--------|------|--------|
| 황금 격류 `goldSurge` | 전투 골드 +60~100% (**최대 롤 = 골드 2배**) | ★5 · 무기/목걸이 |
| 황금 손길 `goldTouch` | 전투 골드 +20~35% | ★4 |
| 결정안 `crystalEye` | 크리스탈 드롭 확률 +50~100% | ★4 |
| 진문 유인 `symbolLure` | 진문 드롭 확률 +20~40% | ★4 |
| 금고의 탐욕 `vaultGreed` | 장비 드롭 확률 +25~50% | ★4 |
| 현자의 기록 `scholar` | 획득 EXP +15~30% | ★4 |
| 소환서 수집 `scrollHoard` | 소환서 드롭 확률 +30~60% | ★4 |

| 전투형 | 효과 | 최소 ★ |
|--------|------|--------|
| 선공 개진 `battleOpening` | 시작 마나 +10~20%p | ★4 |
| 진액 샘 `manaSpring` | 마나 회복 +8~15% | ★4 |
| 지휘의 포효 `leaderRoar` | 아군 공격력 +5~10%p | ★4 |
| 불굴의 방벽 `bulwark` | 소환사 HP +8~15% | ★4 |
| 예리한 감응 `keenSense` | 보드 감응 +10~20% | ★4 |
| 거수 사냥 `giantSlayer` | 보스 스테이지 아군 공격력 +10~18%p | ★4 |

소비처는 집계 헬퍼 `gearAffixTotals(gear)` 하나만 호출한다 (중복 id 제거 + max).

### 드롭 — 황금 금고 5층

- 드롭: 시나리오 보스, **주간 황금 금고**, 이벤트
- 층이 깊어질수록 에너지·웨이브·★가중치가 오른다 (`gearStarWeights` / `gearMinStars`)

| 층 | id | 에너지 | 웨이브 | ★ 구성 |
|----|----|--------|--------|--------|
| 1 입문 | `equip_vault_1` | 6 | 2 | ★1–3 |
| 2 심층 | `equip_vault_boss` | 8 | 3 | ★1–5 (★2–3 중심) |
| 3 봉인 서고 | `equip_vault_3` | 10 | 3 | ★2–5 |
| 4 보물 회랑 | `equip_vault_4` | 12 | 4 | ★2–5 · 최소 ★2 |
| 5 금고의 주인 | `equip_vault_5` | 14 | 4 + 보스 | ★4–5 · 최소 ★4 → **특수 능력 확정** |

- **주간 입장 15회** (5층 합산, ISO 주 기준, 입장 시 차감)
- 해금은 기존 `chainUnlocked` 선형 진행 (`garen_1_4` 게이트 유지)
- 층 깊이만큼 강화 프리셋 부여 (2층 +1 … 5층 +4)
- 강화진에서 가방 장착(슬롯 교체) / 판매
- 판매: 강화도에 비례 마나 환급 · **+12 이상**은 투자 크리스탈의 약 절반 환급 · 특수 능력 1개당 마나 +120
- 가방 초과 시 자동 판매는 **가장 값싼 장비**를 고른다 (특수 능력 붙은 ★5 보호)

## 4. 마나

```text
Mana += BaseRegen * dt
Mana += BoardEventBonus * (1 + BoardSense)
```

- 국면 우위 → 마나 선충전 → 소환사기 선제공 → 스노우볼
- 국면 열세 → 소환사기 지연 → 상징 스펙 의존↑

상세 수치: [combat-formula.md](combat-formula.md)

## 5. 전투 중 행동

1. ATB 풀 → 스톤소환 → 평타/일반 스킬  
2. 마나 풀 + 소환사 턴 → **소환사 스킬** 선택 가능  
3. 일부 소환사 스킬은 **보드 직접 개입** (추가 착수, 청소, Amplify 선언)

### 스킬 키워드

| 키워드 | 효과 |
|--------|------|
| 마나개방 | 광역 + Amplify 폭주 |
| 쌍착수 | 돌 2개 |
| 진문청소 | 일대 돌/금수 제거 |
| 증폭선언 | 짧은 Amplify 고정 |
| 진문수호 | 아군 소환수 실드 |

### Phase 1 스킬

**진문개방** (마나 풀):
- 적 전원 피해
- Amplify +0.15 (스킬 히트에 반영)
- 마나 전량 소모

**증폭선언** (마나 50%+):
- Amplify를 최소 1.12로 끌어올린 뒤 +0.10 (무기 skillPower에 소폭 가산)
- 마나 50% 소모 · 피해 없음

**쌍착수** (마나 35%+):
- 이번 턴 추가 착수 1회 (추천 착수 자동)
- 마나 35% 소모 · 피해 없음
- 사석상점이 뜨면 자동 선택 후 턴 종료

**진문청소** (마나 45%+):
- 적 돌이 가장 많은 지점 기준 **3×3** 돌·토큰 제거
- 제거 수에 비례해 Amplify 소폭 상승 (최대 +0.08)
- 마나 45% 소모 · 피해 없음
- AUTO: 적 돌 4개 이상일 때 증폭선언보다 우선

**진문수호** (마나 40%+):
- 생존 아군 소환수에게 각각 최대 HP의 **18%** 실드
- 마나 40% 소모 · 피해 없음
- AUTO: 아군 소환수 HP 비율이 55% 미만일 때 청소 다음 우선

## 6. 적 소환사

PvE/아레나에 적 소환사가 있으면 **마나 레이스** 성립.

| 콘텐츠 | 적 소환사 |
|--------|-----------|
| 초반 시나리오 (1–2) | 약한 감응 · 각성 0 |
| 중후반 시나리오 | 각성·스킬트리 노드 스케일 · 증폭/청소 AUTO |
| 아레나 / 월드아레나 | 감응 정상 · 각성·스킬트리 강화 · 맞마나 레이스 |

AUTO: 진문개방 → (Amp 낮으면) 증폭선언 → 진문청소 → (아군 부상) 진문수호 → 증폭선언 → 쌍착수.
