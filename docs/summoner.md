# 서머너 (Summoner)

SW에 없는 StoneSummoner 핵심 차별 요소.

## 1. 역할

- 진영 **후열**에 배치 — **공격 대상이 아님** (무적 지휘관)
- ATB · 스톤소환(착수) · 스킬만 수행
- **마나** 풀 시 서머너 전용 스킬 (적 **소환수**에게만 피해)
- 승패: **적 소환수 전멸 = 승리** / **아군 소환수 전멸 = 패배**

파티: **서머너 1(후열) + 몬스터 4(전열)**

---

## 2. 성장

| 항목 | 내용 |
|------|------|
| 레벨 | 서머너 레벨 (건물 해금·기본 스탯) |
| 각성/초월 | 영구 마나·스킬·리더 보너스 (0~5) |
| 스킬 | 소형 스킬 트리 (12노드) |
| 장비 | 몬스터 상징과 **별개** |

### 서머너 스킬 트리 (얕은 스텁)

강화진에서 해금. 선행 노드 + 서머너 레벨 + 마나(/크리스탈).

| 노드 | 효과 |
|------|------|
| 진액 회로 / 국면 눈 / 진문 핵 | 루트 3갈래 (regen·sense·스킬위력) |
| 심연 저장 / 선취 감응 / 개방 집중 | 각 갈래 2단 |
| 지휘 파동 | 리더 ATK · HP (마나+스킬 루트 필요) |
| 쌍착 숙련 / 청소 숙련 | 스킬 마나 할인 · 청소 Amp |
| 증폭 숙련 / 심연 우물 | Lv10 숙련·마나 심화 |
| 전장 합창 | Lv12 리더+스킬 (지휘+쌍착 필요) |

### 서머너 각성 (Phase 1 스텁)

강화진에서 수행. 단계마다 서머너 레벨 게이트 + 마나·크리스탈 소모.

| 단계 (현재→다음) | 최소 Lv | 마나 | 크리스탈 |
|------------------|---------|------|----------|
| 0→1 | 5 | 500 | 3 |
| 1→2 | 8 | 900 | 5 |
| 2→3 | 11 | 1300 | 7 |
| 3→4 | 14 | 1700 | 9 |
| 4→5 | 17 | 2100 | 11 |

단계당 전투 보너스 (누적):

- 마나 regen +0.06 / manaMax +8 / boardSense +0.015 / 시작 마나% +1% / skillPower +0.025
- 서머너 유닛 HP +30 · DEF +3
- 아군 몬스터 ATK +1.2%/단계 · HP +0.6%/단계 (리더형)

## 3. 서머너 장비

### 슬롯 (Phase 1 스텁: 6부위)

| 부위 | 주 효과 축 |
|------|------------|
| 무기 | 스킬 위력 (진문개방 계수) |
| 로브 | 생존 (HP/DEF) |
| 장신구 | 마나 회로 |
| 마법구 | 국면 감응 (보드→마나) |
| 망토 | 생존 + 리더형 ATK% |
| 반지 | 스킬 위력 + 리더형 ATK% |

스타터: **지휘 망토** (리더 +0.8%) · **결속 반지** (리더 +1.0%)  
강화 시 망토/반지 리더 %·생존/스킬이 소폭 상승. 각성 리더와 합산되어 아군 몬스터에 적용.

### 장비 세트 (얕은 5종 · 2/4/6)

| 세트 | 2세트 | 4세트 | 6세트 |
|------|-------|-------|-------|
| 진액 (mana) | regen·manaMax | 시작 마나%·manaMax | regen·manaMax |
| 돌격 (assault) | 스킬 위력·리더 ATK | 추가 스킬·리더 | 추가 스킬·리더 |
| 수호 (guardian) | 서머너 HP/DEF | 추가 HP/DEF | 추가 HP/DEF |
| 감응 (sense) | boardSense | sense·regen | sense·시작마나 |
| 진속 (tempo) | 시작마나·sense | 시작마나·스킬 | regen·리더 |

- 스타터: 무기+반지=돌격2 · 로브+망토=수호2 (즉시 활성)
- 세트 부여: 강화진/CLI `set-gear` · 마나 180 · 부위별 세트 교체
- 6세트: 동일 세트 6부위 장착 시 (풀 모노세트)

### 효과 축

| 축 | 설명 |
|----|------|
| 생존 | 서머너 HP·방어 |
| 마나 회로 | 기본 마나 충전 속도, 시작 마나 %, 상한 |
| 국면 감응 | 따냄·형상·아이템당 보너스 마나 |
| 스킬 위력 | 서머너기 계수·마나 소모 |
| 리더형 | 아군 전원 소폭 버프 |

- 강화: 상징보다 단순 (**+0~+15**) · +9 이후 마나 비용 가속
- 세트: 마나특화 / 돌격 / 수호 / 국면감응 / 진속 — **얕게** (2/4/6세트, 상징과 규모 경쟁 금지) [x]
- 드롭: 시나리오 보스, **주간 장비 금고**, 이벤트
  - 장비 금고 입문/심층 (`equip_vault_*`) — 클리어 시 랜덤 부위·세트 장비 → **가방** 보관
  - 강화진에서 가방 장착(슬롯 교체) / 판매

## 4. 마나

```text
Mana += BaseRegen * dt
Mana += BoardEventBonus * (1 + BoardSense)
```

- 국면 우위 → 마나 선충전 → 서머너기 선제공 → 스노우볼
- 국면 열세 → 서머너기 지연 → 상징 스펙 의존↑

상세 수치: [combat-formula.md](combat-formula.md)

## 5. 전투 중 행동

1. ATB 풀 → 스톤소환 → 평타/일반 스킬  
2. 마나 풀 + 서머너 턴 → **서머너 스킬** 선택 가능  
3. 일부 서머너 스킬은 **보드 직접 개입** (추가 착수, 청소, Amplify 선언)

### 스킬 키워드

| 키워드 | 효과 |
|--------|------|
| 마나개방 | 광역 + Amplify 폭주 |
| 쌍착수 | 돌 2개 |
| 진문청소 | 일대 돌/금수 제거 |
| 증폭선언 | 짧은 Amplify 고정 |

### Phase 1 스킬

**진문개방** (마나 풀):
- 적 전원 피해
- Amplify +0.15 (스킬 히트에 반영)
- 마나 전량 소모

**증폭선언** (마나 50%+):
- Amplify를 최소 1.12로 끌어올린 뒤 +0.10 (무기 skillPower에 소폭 가산)
- 마나 50% 소모 · 피해 없음

**쌍착수** (마나 35%+):
- 이번 턴 추가 착수 1회 (추천 착수 자동)
- 마나 35% 소모 · 피해 없음
- 사석상점이 뜨면 자동 선택 후 턴 종료

**진문청소** (마나 45%+):
- 적 돌이 가장 많은 지점 기준 **3×3** 돌·토큰 제거
- 제거 수에 비례해 Amplify 소폭 상승 (최대 +0.08)
- 마나 45% 소모 · 피해 없음
- AUTO: 적 돌 4개 이상일 때 증폭선언보다 우선
