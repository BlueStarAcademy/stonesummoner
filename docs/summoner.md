# 서머너 (Summoner)

SW에 없는 StoneSummoner 핵심 차별 요소.

## 1. 역할

- 진영 **중앙 슬롯**에 배치되어 **직접 전투 참여**
- HP · ATB · 스톤소환(착수) · 스킬
- **마나** 풀 시 서머너 전용 스킬
- 기본 패배 조건: **서머너 HP 0 = 패배**

파티: **서머너 1 + 몬스터 4**

---

## 2. 성장

| 항목 | 내용 |
|------|------|
| 레벨 | 서머너 레벨 (건물 해금·기본 스탯) |
| 각성/초월 | 서머너 전용 성장 |
| 스킬 | 슬롯 2~3 또는 소형 스킬 트리 |
| 장비 | 몬스터 상징과 **별개** |

---

## 3. 서머너 장비

### 슬롯 (Phase 1: 1~2부위, 이후 확장)

| 부위 | 주 효과 축 |
|------|------------|
| 무기 | 스킬 위력, 일부 ATK |
| 로브 | 생존 (HP/DEF) |
| 장신구 | 마나 회로 |
| 마법구 | 국면 감응 (보드→마나) |
| 망토/반지 | 리더형 소폭 버프 (선택) |

### 효과 축

| 축 | 설명 |
|----|------|
| 생존 | 서머너 HP·방어 |
| 마나 회로 | 기본 마나 충전 속도, 시작 마나 %, 상한 |
| 국면 감응 | 따냄·형상·아이템당 보너스 마나 |
| 스킬 위력 | 서머너기 계수·마나 소모 |
| 리더형 | 아군 전원 소폭 버프 |

- 강화: 상징보다 단순 (+단계 또는 +0~+15)
- 세트: 마나특화 / 돌격 / 수호 / 국면감응 — **얕게** (상징 13종과 규모 경쟁 금지)
- 드롭: 시나리오 보스, 주간 장비 던전, 이벤트

---

## 4. 마나

```text
Mana += BaseRegen * dt
Mana += BoardEventBonus * (1 + BoardSense)
```

- 국면 우위 → 마나 선충전 → 서머너기 선제공 → 스노우볼
- 국면 열세 → 서머너기 지연 → 상징 스펙 의존↑

상세 수치: [combat-formula.md](combat-formula.md)

---

## 5. 전투 중 행동

1. ATB 풀 → 스톤소환 → 평타/일반 스킬  
2. 마나 풀 + 서머너 턴 → **서머너 스킬** 선택 가능  
3. 일부 서머너 스킬은 **보드 직접 개입** (추가 착수, 청소, Amplify 선언)

### 스킬 키워드

| 키워드 | 효과 |
|--------|------|
| 마나개방 | 광역 + Amplify 폭주 |
| 쌍착수 | 돌 2개 |
| 진문청소 | 일대 돌/금수 제거 |
| 증폭선언 | 짧은 Amplify 고정 |

### Phase 1 스킬

**진문개방** 1종만:
- 적 전원 피해
- Amplify +0.15 (2턴)
- 마나 전량 소모

---

## 6. 적 서머너

PvE/아레나에 적 서머너가 있으면 **마나 레이스** 성립.  
Phase 1 시나리오: 적 서머너 단순 AI (기본 regen만, 보드 보너스 약함).
