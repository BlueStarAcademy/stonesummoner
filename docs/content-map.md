## 5. Phase 1 플레이 루프

```text
홈 → 진액 연못 수집
   → 소환진 (초기 스크롤)
   → 강화진 (레벨업)
   → 출정문 → 가렌숲 1-1 ~ 1-4
       → 전투 (착수·Amplify·마나·진문개방)
       → 보상 (마나·EXP·활로 상징)
   → 홈
```

에너지·다계정·길드는 Phase 2.
