# Play Store screenshots

`npm run store:graphics` writes seed phone PNGs here (`01-home-island.png`, `02-battle-circle.png`).

Before Play publish, **replace** them with ≥2 captures from the Android emulator or a device (9:16 preferred):

1. Auth / home island
2. Battle (magic circle) or monster book

Upload in Play Console → Store listing → Phone screenshots.

Feature graphic and app icon are also generated by `npm run store:graphics` (repo root).
